# A gratificação do profissional é sigilosa para o Dono da Obra

Nada que o Dono da Obra vê (PDF do orçamento, pedido, nota) pode revelar a existência ou o valor da Gratificação do Profissional. A Gratificação Fixa é registrada internamente no campo "Outras Despesas" do app, mas no PDF do cliente ela é diluída nos preços dos itens, nunca como linha avulsa. Essa é uma restrição comercial que não aparece no código.
