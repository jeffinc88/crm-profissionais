# CRM operado só pela fábrica, sem acesso dos representantes

A base de pedreiros é operada apenas pela fábrica (Jefferson e mais uma pessoa). Os representantes comerciais não veem nem alimentam o CRM, porque eles têm interesse em esconder do cliente que a laje é da Carvalho; o relacionamento direto com o pedreiro serve justamente para a fábrica ter um canal próprio que não dependa deles.
