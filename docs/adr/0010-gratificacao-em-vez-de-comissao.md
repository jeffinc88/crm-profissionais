# "Gratificação" em vez de "comissão" para o que se paga ao profissional

Todo texto do CRM (telas, mensagens, documentos) chama de **gratificação** o valor pago ao profissional por uma indicação que vira venda. A decisão foi do Jefferson, por cautela jurídica. Os nomes internos do banco (`crm_comissoes`, `tipo_comissao` etc.) continuam como estavam, porque renomear tabelas em produção traria risco sem benefício para quem usa o sistema.
